# Guidon campaign design contract

This is a short product film, not a redesign of Guidon's interface. The screenshots remain the source of truth for the application UI.

## Palette

- Canvas: `#0b0d10` (Guidon dark background)
- Main text: `#e8eaed` (Guidon dark text)
- Brand blue: `#1d4fd8`
- Bright blue accent: `#4d8dff`
- White is reserved for the existing white wordmark and screenshot surface.

## Type

- Display and overlay copy: Montserrat, used as a video-safe companion to the app's Geist sans.
- Small technical labels: JetBrains Mono.
- Text remains at video scale: 22px labels, 56px end line, 92px opening.

## Treatment

- Dark Guidon canvas around real, cropped product screens.
- Screenshots use only the task board, decision rationale, and project-memory areas. Crops exclude profile names, email, and activity feed.
- A subtle brand-blue light sits behind the end card. No generic SaaS illustrations or invented metrics.
- UI panels keep the screenshot's original color and visual hierarchy.
